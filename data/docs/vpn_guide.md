# VPN 연결 문제 해결

VPN 연결 오류 720이 발생하면 먼저 클라이언트 버전과 네트워크 어댑터 상태를 확인합니다. Windows 장치 관리자에서 네트워크 어댑터 오류가 있는지 확인한 다음 VPN 클라이언트를 다시 실행합니다.

VPN 연결 문제가 계속되면 VPN 설정과 인증 정보를 확인하고 IT 지원팀에 오류 코드, 운영체제 버전, 발생 시각을 전달합니다.

설치 전에 운영체제 지원 버전과 관리자 권한 여부를 확인해야 합니다.
